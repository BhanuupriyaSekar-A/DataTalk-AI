================================================================================
TROUBLESHOOTING QUICK FIXES
================================================================================

Problem: "java: command not found" or Java version < 17
Solution: 
  - Download Java 17+ from https://www.oracle.com/java/technologies/downloads/#java17
  - Restart Command Prompt after installation
  - Run: java -version

Problem: "mvn: command not found"
Solution:
  - Download Maven from https://maven.apache.org/download.cgi
  - Unzip to a folder (e.g., C:\maven or /opt/maven)
  - Add to system PATH
  - Restart Command Prompt
  - Run: mvn -version

Problem: "No AI provider configured"
Solution:
  - Check .env file exists in project root
  - Verify GROQ_API_KEY is filled (not empty)
  - Restart the application

Problem: Port 8081 already in use
Solution:
  - Run with different port: mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=8091
  - Then access at: http://localhost:8091/datatalk/login

Problem: Database connection failed
Solution:
  - Verify DB_URL, DB_USER, DB_PASSWORD in .env are correct
  - Check internet connection (Neon is cloud-based)
