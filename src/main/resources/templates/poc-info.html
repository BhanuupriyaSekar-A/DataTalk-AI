DataTalk AI

AI-powered natural-language database reporting – personal Proof of Concept

POC complete (Phases 1–3) 1 pending DB step: phase3-migration.sql

Project Overview

Users log in and ask business questions in plain English. An AI model generates PostgreSQL SQL; the backend validates it, applies the user's role and customer restrictions and runs it read-only. Results are shown as tables and charts and can be exported to PDF or Excel.

Sample domain: cashless payments and device management (synthetic data only).

How It Works

1

Ask

Question in plain English

2

Generate SQL

Role-filtered schema sent to Groq / Gemini / NVIDIA (with fallback)

3

Validate

JSqlParser: SELECT/CTE only, allowed tables, blocked columns

4

Execute

Read-only, customer/device scoped, 30 s timeout, row limits

5

Show & export

Table, chart, filters, pagination, PDF / Excel

Features

  • Login / logout, BCrypt passwords, sessions, login history
  • Roles: ADMIN, BUSINESS, MANAGER, CUSTOMER
  • Customer-level and device-level data isolation
  • AI chat with follow-up questions and saved context
  • AI providers: Groq, Gemini, NVIDIA with automatic fallback; answering model shown in UI
  • Schema-aware SQL generation and parser-based SQL validation
  • Tables, charts, filters, pagination, explanations
  • 11 predefined reports (payments, devices, settlements, customers)
  • Chat history and SQL cache for repeated questions
  • PDF / Excel export with background jobs for large results
  • Export job tracking in app.export_job
  • Query Analytics page (ADMIN only)
